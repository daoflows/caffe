## 🚀 快速开始（3步）

### 第一步：安装 Docker（仅首次需要）

如果您的电脑还没有安装 Docker，请先安装：

- **Windows/Mac**：下载并安装 Docker Desktop
  下载地址：https://www.docker.com/products/docker-desktop/
- **Linux**：按官方文档安装 Docker Engine

安装完成后，请确保 Docker 正在运行（任务栏/系统托盘中的 Docker 图标显示正常状态）。

### 第二步：加载软件环境

1. 打开**命令行**：
   - Windows：按 `Win + R`，输入 `cmd` 回车
   - Mac：打开"终端"应用（在启动台 → 其他 中）
2. 使用 `cd` 命令进入您存放文件的文件夹，例如：
   ```
   cd C:\Users\您的用户名\Downloads
   ```
3. 执行加载命令：
   ```
   docker load -i __TAR_FILENAME__
   ```
4. 等待加载完成（约30秒-2分钟），看到 `Loaded image` 字样即表示成功

### 第三步：启动并使用

1. 执行启动命令：
   ```
   docker run -d --name __CONTAINER_NAME__ -p __HOST_PORT__:__CONTAINER_PORT__ __IMAGE_NAME__
   ```
2. 等待约 __WAIT_SECONDS__ 秒
3. 打开浏览器，在地址栏输入：**http://localhost:__HOST_PORT__**
4. 当提示输入 Token/密码/访问码时，输入：
   ```
   __ACCESS_TOKEN__
   ```
5. __POST_LAUNCH_STEP__

🎉 **恭喜！您已成功启动 __PRODUCT_NAME__！**

## ⚡ 常用操作

### 停止使用

关闭浏览器后，在命令行执行：
```
docker stop __CONTAINER_NAME__
```

### 再次使用

之前已加载过，不需要重新加载镜像，直接执行：
```
docker start __CONTAINER_NAME__
```
然后浏览器打开 http://localhost:__HOST_PORT__ 即可。

### 完全重置（删除所有数据重新开始）

```
docker rm -f __CONTAINER_NAME__
```
然后重新执行第三步的启动命令。

⚠️ **注意**：完全重置会丢失您的所有修改数据。如果有重要文件，请先下载备份。
